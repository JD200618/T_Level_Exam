# Archive

This folder stores project material that is no longer part of the active GLH runtime app but may still be useful as historical reference.

## Current archived items
- `frontend-reference-ui/` contains technical showcase pages that were removed from the live student demo.
- `unused-ui-components/` contains UI-kit files that were not used by the working application.
- `legacy-ui-primitives/` contains the older split-out button/card/input/label/textarea/badge wrappers that were replaced by a simpler shared `core.tsx` file.

These files are kept for traceability, not because the live app depends on them.
