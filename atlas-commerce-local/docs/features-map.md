# Features map

## Client need to project feature mapping

### 1. Producer and local-buying information
Current status:
- implemented at prototype level
- homepage and catalogue now surface producer names, locations, production methods, and local-buying value
- could still be improved later with dedicated producer profile pages if required

### 2. Product catalogue with transparent pricing and availability
Current status:
- implemented
- product API and frontend shop view exist
- pricing and stock availability are present in the current data flow

### 3. Orders for collection or delivery
Current status:
- implemented
- checkout now stores collection or delivery choice plus a requested time window and customer note

### 4. Customer accounts and order history
Current status:
- implemented
- login, profile, addresses, payment methods, and order history APIs exist

### 5. Producer dashboard
Current status:
- implemented in prototype form
- inventory, orders, customers, and analytics surfaces exist
- producers can now edit stock, price, summary, producer details, and featured state from the dashboard

### 6. Order management, scheduling, and tracking
Current status:
- partially implemented with a stronger base
- order management exists and requested time windows are now stored and shown to staff and customers
- later work could add more explicit dispatch or tracking milestones if required

### 7. Loyalty scheme
Current status:
- not yet implemented as a full feature
- should be treated as an enhancement item unless prioritised in the next build phase

### 8. Accessibility features
Current status:
- needs formal review and documentation
- should include keyboard flow, clear labels, colour contrast, and readable layout decisions

## Priority interpretation
### Core prototype priorities
- producer and local-value information
- catalogue with pricing and availability
- cart and checkout
- account management and order history
- producer dashboard

### Secondary priorities
- scheduling and tracking refinements
- accessibility review and documentation
- loyalty scheme if time allows
