Local-only prototype scaffold prepared for later transfer to a desktop machine.

## Intended stack
- Backend: Django + Django REST Framework
- Database: SQLite
- Frontend: existing frontend code
- Editor: VS Code

## Root structure
- `backend/` Django backend
- `frontend/` existing frontend code goes here
- `docs/` setup notes
