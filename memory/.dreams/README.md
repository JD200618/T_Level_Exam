# Dreams Layer

This is the speculative layer.

Use it for:
- pattern synthesis
- half-formed structures
- architecture intuitions
- metaphor that may later become design
- possible futures that are not yet solid enough for core memory

Rules:
- Dreams are **not facts**.
- Dreams are **not commitments**.
- Dreams can inspire action, but should be promoted into normal memory, notes, or docs only after they survive scrutiny.
- The value of dreaming is not certainty. The value is connection.
